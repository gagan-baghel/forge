What's inside

A workspace, not a chat box.

Agents here are things you build, give tools to, schedule and keep running — not a tab you leave open.

Computer access

Let an agent use the machine. On a leash.

Turn it on per agent and it can run commands, write files, take screenshots and click — every action stops and shows you exactly what it's about to do.

  • Deny is the default; nothing runs unasked
  • Scoped to your home folder; .ssh, .aws and other key folders are blocked outright
  • Text from web pages and files can't quietly steer it — those turns get a louder warning

Knowledge

Agents that know your stuff — and remember.

Drop in PDFs, notes and exports. Before every answer Forge finds the passages that matter and hands them over, using a search model that runs on your Mac.

Memory is the other half: short facts an agent keeps across conversations. Write them yourself, or let the agent save them — with your OK first, if you like.

Getting started

Three steps. No terminal.

You don't need Node, Rust, a package manager, or any idea what those are.

01

Download

One universal build for Intel and Apple Silicon Macs.

02

Drag to Applications

The usual Mac install: open the disk image, drag Forge across.

03

Open and pick a runtime

Point Forge at Claude Code, or paste an API key. That's the whole setup.

After that, it updates itself. When a new version is out, an Update button appears in the sidebar — one click installs it and restarts.

Questions

The honest answers.

macOS says Forge is damaged. Is it?

No. You may see "Forge is damaged and can't be opened" or "Apple cannot check it for malicious software." macOS says that about any app whose developer hasn't paid Apple's yearly signing fee — it's about the paperwork, not the app.

To get past it once: open Forge and let it be blocked, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. You won't be asked again — and updates install without it.

Does my data go anywhere?

Your agents, chats, keys, documents and memory stay on your Mac. There's no account and no Forge server to send them to.

Three things use the network, because of what they are: the conversation with Claude itself, a one-time ~33 MB download of the local search model, and a check for new Forge versions on GitHub. Offline, search falls back to keyword matching.

What does it cost?

Forge is free. Pointed at Claude Code, it runs on the subscription you already have and meters nothing. With an API key you pay Anthropic directly for tokens — Forge shows the running total either way.

How do updates work?

Forge checks for a new release when it opens and every few hours. When there is one, an Update button appears; it downloads the new version, checks it was signed by the project, installs it and restarts. Builds without a valid signature are refused.

Can someone send me a pack that does something nasty?

Imported packs arrive scrubbed: no bot tokens, no paired phones, no remote control, and every MCP server switched off until you've looked at it. Anything that touches your machine still asks first.

Windows or Linux?

Not yet. Forge is built on Tauri, which supports both, so it's a matter of when — not a rewrite. Until then you can build it yourself from the source.
